# Kubernetes Bookstore App 📚

A scalable, containerized Python application deployed on Kubernetes. This project demonstrates stateful database management using MongoDB StatefulSets and a Flask API.

## 🏗 Architecture
* **API:** Flask (Python) REST API
* **Database:** MongoDB (StatefulSet with PersistentVolume)
* **Orchestration:** Kubernetes (Docker Desktop / Minikube)
* **Containerization:** Docker

## 🛠 Data Integrity Report
During the initial data validation phase, a formatting inconsistency was identified in the provided `bookstore.json` dataset.

**Issue Identified:**
Books 3 and 4 had their `isbn` and `title` keys swapped.
* **Impact:** This structural error would prevent correct indexing and could cause application failures when performing CRUD operations based on the ISBN primary key.
* **Resolution:** Instead of dropping the malformed rows (which would result in inventory loss), the dataset was manually sanitized to correct the key-value pairs before ingestion. This ensures 100% data preservation and application stability.
